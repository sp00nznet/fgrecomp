# Family Guy: The Quest for Stuff -- host contract.
#
# Griffin (TinyCo's engine) is a cocos2d-x 4.0 fork, so the contract is not
# bespoke: these are cocos2d-x's own JNI entry points, and the Java side that
# called them is public source. Read Cocos2dxRenderer.java, Cocos2dxActivity.java
# and Cocos2dxHelper.java at the v4.0 tag to see exactly what each one is handed
# and on which thread.
#
# Of libfg.so's 92 Java_* exports, these are what a desktop host must drive.
# The other 53 are ad networks, Facebook, Google Play, Sentry, push and IAP --
# stubbed, or answered by the server.
#
# Discover this list for another title with:  arc_host <library.so>
